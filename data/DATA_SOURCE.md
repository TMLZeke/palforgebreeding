# Palworld 1.0 data source

This project pins breeding and pal data from **tylercamp/palcalc** game-file exports.

| File | Role |
|------|------|
| `db.json` | Pals, breeding power, work suitability, standard passives, gender ratios |
| `breeding.json` | Full parent→child matrix for the current game data |

## Refresh for a new patch

1. Download the latest files from:
   - https://raw.githubusercontent.com/tylercamp/palcalc/main/PalCalc.Model/db.json
   - https://raw.githubusercontent.com/tylercamp/palcalc/main/PalCalc.Model/breeding.json
2. Replace the copies in this `data/` folder.
3. From `web/`, run `npm run data` (or `npm run build`).

The browser consumes `web/public/dataset.json`, which is generated by `scripts/build-dataset.mjs`.

## Notes

- Early Access breeding tables are **not** used.
- Dataset meta in the UI shows `gameVersion`, `dbVersion`, pal/combo counts, and generated date.
- Gender-specific breeding in the current export: Katress × Wixen only.
